# 룬 리스트 접근성 보장 및 추적 아이템 관리 최적화 계획

## 1. 문제 정의
- 사용자가 추적 아이템(`샤코 3스킬 2소켓` 등)을 여러 개 추가할수록 좌측 컬럼 상단의 카드 보드가 세로로 끝없이 늘어남.
- 이로 인해 PD2의 핵심 기준 데이터인 **하이룬(Zod~Lem) 및 주요 화폐 시세표(`RuneMatrixTable`)가 너무 밑으로 밀려나**, 매번 휠 스크롤을 길게 내려야 하는 접근성 저하 문제 발생.

---

## 2. 해결 방안 제안 (3가지 옵션 비교)

| 옵션 | 설명 | 장점 | 단점 |
| :--- | :--- | :--- | :--- |
| **옵션 A (강력 추천 🌟)<br>스마트 콤보형** | **1) 접기/펼치기 (Collapse)**<br>**2) 보드 내부 Max-Height 스크롤 (카드 4개 초과 시 자체 스크롤)**<br>**3) 좌측 헤더 뷰 전환 탭 ([전체] / [룬 시세] / [내 아이템])** | • 룬 리스트 위치가 항상 화면 중간 이상으로 고정 보장됨<br>• 접기 한 번으로 룬 리스트 최상단 직행 가능<br>• 필요 시 탭 전환으로 화면 전체 집중 가능 | 기존 컴포넌트에 상태 및 컨트롤 UI 추가 필요 |
| **옵션 B<br>완전 탭(Tab) 분리형** | 좌측 컬럼을 `[하이룬 & 화폐 시세]` 탭과 `[내 커스텀 추적]` 탭으로 100% 분리 | 매우 심플하고 각 화면이 깔끔함 | 룬 시세와 내 아이템을 한 화면에서 동시에 비교 불가 |
| **옵션 C<br>상하 2단 독립 스플릿** | 좌측 영역을 상단(커스텀 보드 50%)과 하단(룬 리스트 50%)으로 각각 분할 스크롤 | 두 데이터가 항상 고정 분할됨 | 세로 화면이 좁은 모니터에서 답답할 수 있음 |

> **추천 방식**: **옵션 A (스마트 콤보형)**
> - 평소: 커스텀 보드가 최대 높이(약 360px, 카드 4개 높이)로 제한되어 내부 스크롤되므로, **룬 리스트는 언제나 화면 40% 지점부터 바로 보임**.
> - 접기 버튼 1클릭: 커스텀 보드가 1줄(배지만 표시)로 쏙 접히고, **룬 리스트가 즉시 화면 맨 위로 올라옴**.
> - 좌측 상단 탭 필터: `[전체 보기]` / `[✨ 룬 시세표]` / `[🎯 추적 아이템]`으로 언제든 1초 만에 원하는 뷰만 단독 집중 가능.

## 3. 세부 구현 계획

### 1단계: `CustomWatchlistBoard.tsx` 개선
1. **접기/펼치기 (Collapse/Expand) 기능 추가**:
   - 로컬 상태 `isCollapsed` 추가 (사용자가 접었는지 여부 기억).
   - 헤더에 `ChevronDown` / `ChevronUp` 토글 버튼 배치.
   - 접혔을 때는 카드 목록을 숨기고 헤더 우측에 `등록된 N개 아이템 요약 칩` 표시.
2. **내부 Max-Height 스크롤 적용**:
   - 펼쳐진 상태일 때 `max-h-[360px] overflow-y-auto` 적용.
   - 아이템이 10개, 50개가 되어도 보드 전체 높이가 커지지 않고 내부에서 매끄럽게 스크롤.

### 2단계: 좌측 상단 뷰 필터 세그먼트 컨트롤 추가
- 좌측 컬럼 상단에 가벼운 세그먼트 버튼 제공:
  - `[전체 (기본)]` : 커스텀 보드 + 룬 시세표 + 룬 계산기
  - `[룬 & 화폐]` : 룬 시세표를 최상단에 꽉 채워서 집중 보기
  - `[내 추적 아이템]` : 등록한 커스텀 카드들을 3열~4열 와이드 그리드로 집중 관리

### 3단계: 단위 테스트 및 Puppeteer E2E 브라우저 검증
- 모달로 새 아이템 추가 후 접기/펼치기 클릭 동작 및 룬 시세표 접근성 검증.
- 스크린샷 캡처 및 Vitest 테스트 수행.

### 4단계: Tauri 최종 릴리즈 빌드 & 문서화
- `APP_MAP.md` 및 `docs/unit_test_results.txt` 최신화.
