# 옵션 B (완전 탭 분리형) 구현 계획

## 1. 개요
- 좌측 컬럼 상단에 명확한 2개 탭([✨ 하이룬 & 화폐 시세표] / [🎯 내 커스텀 추적 아이템 ({count})])을 제공하여,
  추적 아이템이 아무리 많아져도 하이룬 시세표의 접근성이 100% 고정 유지되도록 구조 분리.

## 2. 세부 변경 사항
1. **`App.tsx` 좌측 탭 상태 추가 (`leftTab: 'runes' | 'custom'`)**:
   - 기본 탭: `'runes'` (하이룬 시세표 즉시 접근)
   - 새 아이템 등록 시: 자동으로 `'custom'` 탭으로 전환되어 방금 추가된 카드를 즉시 확인할 수 있도록 UX 개선.
2. **좌측 컬럼 상단 네비게이션 탭 바 구현**:
   - 세련된 다크 테마 탭 UI (선택된 탭 하이라이트 배지, 아이템 개수 카운트 뱃지).
   - 우측에는 `+ 추적 아이템 추가` 퀵 버튼 배치.
3. **조건부 렌더링**:
   - `'runes'` 선택 시: `RuneMatrixTable` + `RuneBreakCalculator`만 렌더링.
   - `'custom'` 선택 시: `CustomWatchlistBoard`를 좌측 영역 전체 높이에서 시원하게 렌더링.
4. **테스트 및 검증**:
   - Vitest 단위 테스트 업데이트.
   - Puppeteer E2E 브라우저 제어 테스트: 탭 전환 및 아이템 추가 후 자동 탭 전환 검증.
   - Tauri 데스크탑 빌드.
